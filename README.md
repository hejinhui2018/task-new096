# 浏览器端工业 CT 缺陷复核台（复核演示）

> **免责声明：本项目仅用于复核流程的教学与演示。**
> 坐标变换、26 邻域连通、物理量计算、表面距离与门禁逻辑均为教学级实现，
> **不得用于真实航空铸件的检测判定或产品放行。**

针对航空铸件 CT 复核中“跨视图记坐标、轮廓稍有偏差就可能拆错缺陷或误判贯穿”的痛点，
在浏览器内完成：**导入带体素间距与原点的灰度切片 → 三正交视图勾画 → 映射到同一体素坐标
→ 26 邻域重建连通缺陷 → 计算体积/包围盒/主轴/到外表面最短物理距离 → 缺层/方向冲突/轮廓不闭合时阻止定量结论**。

## 快速开始

```bash
npm install
npm run dev        # 本地开发
npm test           # 全部单元/集成测试（Vitest）
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览构建产物
```

打开后建议先点击右上角 **「载入模拟标记（表面+气孔+裂纹）」**，立即看到完整的
三视图叠加、缺陷列表、体素预览与测量证据。下拉可切换到 **缺层模拟件（z=17 缺失）**，
观察定量结论如何被门禁整体阻止。

## 功能一览

- **三正交视图联动**：轴位 AX(XY@z)、矢位 SAG(YZ@x)、冠位 COR(XZ@y)。
  - 窗宽窗位滑块实时调整灰度映射；滚轮或滑块逐层浏览。
  - **十字光标**三视图联动定位同一体素点，顶部显示体素下标与物理坐标。
- **勾画与标记**：
  - 轮廓工具逐点单击，回到首点吸附**闭合**；候选轮廓先以黄色/绿色预览，
    点「采用候选」才纳入，「放弃」即可丢弃。**未闭合轮廓可采用，但必然触发门禁。**
  - 缺陷笔/擦、表面笔/擦（可调半径），一次拖拽是一条可撤销记录。
- **统一坐标重建**：三视图的任何编辑都通过同一 `planeToVoxel` 映射进入 x/y/z 体素空间，
  按 **26 邻域（共享面/边/角）** 求连通分量；两个标签若被体素桥接会自动合并并显示双方名称。
- **定量测量**（仅在门禁通过时输出）：
  - 体积 = 体素数 × Δx·Δy·Δz（mm³，支持各向异性间距与方向余弦）；
  - 轴对齐包围盒（体素范围 + 物理尺寸）、质心（体素/物理坐标）；
  - **主轴**：物理坐标空间 PCA，Jacobi 特征分解给出三个主轴方向与 RMS 扩展（mm）；
  - **到外表面最短物理距离**：以全部表面体素为多源、26 向边权为物理位移长度的
    Dijkstra 距离场，并回溯实现该距离的「缺陷体素–表面体素」证据对（3D 预览中以虚线显示）。
- **门禁（阻止定量结论）**：
  | 代码 | 触发条件 | 影响范围 |
  |---|---|---|
  | `MISSING_SLICES` | 清单未连续覆盖 z=0..dims.z−1 | 全局：所有缺陷不给任何测量值 |
  | `DIRECTION_CONFLICT` | 方向矩阵非正交/含镜像（det≠+1）/长度≠9 | 全局 |
  | `OPEN_CONTOUR` | 该缺陷含未闭合采纳轮廓 | 该缺陷 |
  | `EMPTY_DEFECT` | 缺陷体素为空 | 该缺陷 |
  | `NO_SURFACE_MASK` | 尚未标记外表面 | 仅表面距离不可得，体积类结论仍出 |
  - 导入阶段另有结构校验：z 越界/重复、文件缺失、字节数与维度不符直接拒绝导入。
- **撤销/重做与本地保存**：快照式历史（默认 100 步），文档与 UI 状态存于 `localStorage`，
  **刷新页面后编辑与撤销栈完整恢复**。
- **首屏证据**：缺陷列表（标签、体素数、跨层范围、体积、表面距离）、可旋转的体素预览、
  点选缺陷后三视图跳到质心并列出**参与切片**（点击 z 芯片跳转）。
- **导入自己的清单**：工具栏「导入切片清单…」，格式见下。

## 清单格式

一个 JSON 清单 + 逐切片原始灰度文件（无文件头，紧凑存储，行优先 y 行 x 列）：

```json
{
  "name": "demo-casting",
  "dims": { "x": 48, "y": 48, "z": 40 },
  "spacing": { "x": 0.5, "y": 0.5, "z": 0.8 },
  "origin": { "x": -12, "y": -12, "z": 0 },
  "direction": [1,0,0, 0,1,0, 0,0,1],
  "intensityRange": { "min": 0, "max": 2200 },
  "dtype": "uint16",
  "endian": "little",
  "slices": [
    { "z": 0, "file": "slice_000.raw" }
  ]
}
```

- `dtype`：`uint8` / `uint16` / `float32`；字节序默认小端。
- 物理坐标约定：`P = direction · ((voxel + 0.5) * spacing) + origin`。
- `direction` 必须是行列式 +1 的正交矩阵；缺省视为单位阵；镜像翻转判为方向冲突。
- `slices` 必须连续列全 z=0..z−1，缺层即触发门禁。

## 内置模拟数据

`src/domain/mock.ts` 确定性合成（LCG 噪声，无需外部资源），一个 48×48×40 椭球铸件：

- **气孔 A / 气孔 B**：中心相距 8 体素、半径 3，边缘间隔 2 体素 ——
  26 邻域下恰好是**两个独立分量**，验证“相邻气孔不误并”；
- **近表面裂纹**：沿 z 的细线，距 +x 外壳 1 个 x 间距，最短表面距离恰为 **0.5 mm**；
- **缺层变体**：清单缺失 z=17，顶部红色横幅与每个缺陷的「阻止」状态联动。

## 代码结构

```
src/domain/        纯领域逻辑（无 React 依赖，全部可单测）
  coordinates.ts   线性索引、体素↔物理、方向余弦校验、三视图平面映射、26 邻域
  geometry.ts      轮廓闭合判定、扫描线光栅化、多边形面积
  masks.ts         三视图轮廓/笔刷 → 统一体素索引
  connectivity.ts  26 邻域连通分量（BFS）
  distance.ts      多源加权 Dijkstra 表面距离场 + 证据回溯
  measurements.ts  体积/包围盒/质心/物理空间 PCA 主轴
  gates.ts         缺层/方向/未闭合/空缺陷/无表面 门禁
  reconstruction.ts 编辑序列 → 连通 → 门禁 → 测量 的纯函数流水线
  history.ts       快照式撤销/重做（可 JSON 序列化恢复）
  manifest.ts      清单解析、结构校验、字节解码与组装
  mock.ts          内置模拟数据
src/state/         AppStore（localStorage 持久化）、React 绑定
src/render/        截面灰度采样与窗宽窗位光栅化
src/components/    三视图、工具栏、缺陷列表、证据面板、3D 预览、导入框
test/              Vitest 测试（59 个）
```

## 技术栈

React 18 + TypeScript（strict）+ Vite 5 + Vitest。无第三方几何/可视化库，
连通性、距离场、PCA 与体素投影均为手写实现；所有数据仅保存在浏览器本地。
