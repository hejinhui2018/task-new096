# 工业 CT 缺陷复核台（演示）

> **仅用于复核流程演示。** 本工具不是医疗器械/工业检测设备，未做任何计量溯源与
> 缺陷判定标准符合性验证，**不得用于真实铸件的验收、拒收或安全相关结论**。

面向航空铸件 CT 复核场景：复核员导入带体素间距与原点的灰度切片清单后，在
三正交视图中调窗、逐层勾画缺陷掩膜并标记零件外表面；系统把三视图编辑映射到
同一体素坐标，按 **26 邻域** 重建连通缺陷，计算体积、包围盒、主轴与到外表面的
最短物理距离，并在数据不满足前提时**阻止定量结论**。

## 运行

```bash
npm install
npm run dev        # 开发
npm run test       # 45 个单元/集成测试
npm run build      # 类型检查 + 生产构建
```

## 功能与操作

- **三正交视图**（横断/冠状/矢状）：同一体素坐标系，任一视图点击十字光标，
  其余两视图自动跳到对应层并画出十字线。
- **窗宽窗位**：右键在图像上拖拽（横向=窗宽，纵向=窗位），或工具栏数值输入。
- **勾画缺陷 / 标记外表面**：选择工具后在当前层逐点点击；点击首点或"闭合"
  闭合多边形；候选轮廓先以虚线**预览**，"采用"后才进入掩膜与定量分析。
  未闭合就采用的轮廓会被门禁拦截（演示门禁行为）。
- **撤销/重做**：Ctrl+Z / Ctrl+Shift+Z（或 Ctrl+Y），轮廓历史可序列化，
  刷新页面后从 localStorage 自动恢复（含撤销栈）。
- **缺陷列表**：26 邻域连通分量，点击行选中并把十字光标跳到质心；
  测量证据面板给出体积、包围盒（体素+物理）、质心、主轴（协方差特征分解）、
  细长比、到外表面最短距离，以及**参与切片**（点击可跳层）。
- **体素预览**：缺陷/外表面点云三维预览，拖拽旋转。
- **自动外表面**：阈值分割 + 边界泛洪，只把贴"外部背景"的零件体素算作外表面
  （气孔内壁等内部空腔不计入，避免低估缺陷到表面的距离）。
- **模拟数据**：内置圆柱形铸件（64×64×48，0.5×0.5×0.8 mm），含两个相邻气孔
  （26 邻域下仍分为两个缺陷）、一条近表面裂纹；"缺层"变体缺 z=24 层，用于
  演示门禁阻断。

## 质量门禁（阻止定量结论的条件）

| 门禁 | 触发 | 影响 |
|---|---|---|
| `MISSING_SLICES` | z 层不连续（缺层） | 阻止全部定量结论 |
| `METADATA_CONFLICT` | 逐片 spacing/origin/orientation 与全局不一致或层号重复 | 阻止全部定量结论 |
| `UNCLOSED_CONTOUR` | 存在未闭合轮廓 | 阻止全部定量结论 |
| `NO_SURFACE` | 未标记外表面 | 仅阻止"到表面距离" |

## 切片清单（manifest）格式

```json
{
  "kind": "ct-slice-manifest",
  "version": 1,
  "width": 64, "height": 64,
  "spacing": [0.5, 0.5, 0.8],
  "origin": [0, 0, 0],
  "orientation": "RAS",
  "slices": [
    { "index": 0, "bits": 16, "data": "<base64，行主序，小端 16bit 或 8bit>",
      "spacing": null, "origin": null, "orientation": null }
  ]
}
```

- 体数据深度 `nz` 由最大 `index + 1` 推断；空缺 index 即缺层。
- 逐片 `spacing/origin/orientation` 若给出且与全局不一致 → 元数据冲突门禁。
- 全部数据保存在浏览器 localStorage，不离开本机。

## 坐标与算法约定

- 体素坐标 `(x,y,z)` 为整数索引；物理坐标 = `origin + (voxel+0.5) * spacing`（体素中心）。
- 视图映射：axial(u=x,v=y，法向 z)、coronal(u=x,v=z，法向 y)、sagittal(u=y,v=z，法向 x)。
- 连通性：26 邻域（面/棱/角相邻均连通），迭代式 BFS 标记。
- 主轴：物理坐标下体素云协方差矩阵的 Jacobi 特征分解（特征值降序）。
- 表面距离：以外表面体素为源点的 26 邻域多源 Dijkstra，边长为各向异性
  物理长度（chamfer 近似，非精确欧氏距离变换）。
- 持久化键：`localStorage["ct-review-v1"]`。

## 测试覆盖（tests/）

- `coords.test.ts` — 三视图 ↔ 体素坐标双向映射与视图尺寸
- `connectivity.test.ts` — 26 邻域连通分量（面/棱/角、间隙、桥接、相邻气孔分离）
- `measure.test.ts` — 体积/包围盒/质心/主轴（含各向异性间距）与 Jacobi 特征分解
- `surface.test.ts` — 表面距离场（平面/对角/各向异性）与外表面提取（孔洞内壁排除）
- `gates.test.ts` — 缺层门禁、方向/间距元数据冲突、未闭合轮廓、无外表面、清单解析
- `history.test.ts` — 撤销/重做、序列化恢复（含撤销栈）、损坏数据回退
- `raster.test.ts` — 轮廓栅格化（含跨视图层归属）与模拟数据端到端派生管线
